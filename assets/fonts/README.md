# Шрифты

Отдаются с этого же домена: сторонних запросов у сайта нет.

| Файл | Шрифт | Подмножество |
|---|---|---|
| `jetbrains-mono-*.woff2` | JetBrains Mono | латиница, латиница-расширенная, кириллица, кириллица-расширенная |
| `space-grotesk-*.woff2` | Space Grotesk | латиница, латиница-расширенная |

Оба шрифта распространяются по лицензии SIL Open Font License 1.1 — тексты лицензий рядом, в `LICENSE-JetBrainsMono.txt` и `LICENSE-SpaceGrotesk.txt`. Она разрешает размещать файлы на своём сервере.

**Space Grotesk не содержит кириллицы** — так у него и на Google Fonts. Русские заголовки поэтому отображаются следующим шрифтом из стека, то есть JetBrains Mono. На вид ничего не изменилось: до переноса работало ровно так же.

Файлы вариативные: один файл покрывает все начертания своего подмножества, поэтому их шесть, а не шестнадцать. Правила `@font-face` лежат в начале `assets/css/main.css`.
